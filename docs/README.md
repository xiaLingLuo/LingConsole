# LingConsole 1.2.8 文档

LingConsole 由 Panel、Daemon、共享组件和插件 API 组成。默认单个 JAR 同时启动 Panel 与本地 Daemon，也可以拆分部署，由一个 Panel 管理多个远端 Daemon，通过AGPL-3.0进行开源。

## 默认端点

| 服务   | 默认地址               | 主要入口                    |
|--------|------------------------|-----------------------------|
| Panel  | `http://0.0.0.0:55600` | 页面、`/api`、`/socket.io`  |
| Daemon | `http://0.0.0.0:55700` | `/consoleapi`、`/socket.io` |

默认地址会监听所有网卡。生产环境应按实际拓扑修改监听地址、启用防火墙，并通过反向代理提供 TLS。
